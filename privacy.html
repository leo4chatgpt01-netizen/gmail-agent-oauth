Privacy Policy

Last updated: 2026-10-27

gmail-agent is a personal tool used only by its owner, with the owner's own Google account.

  • Data accessed: email messages and labels in the owner's Gmail account, via the Gmail API scope gmail.modify.
  • How it is used: to read verification codes, summarise recent mail for the owner, and send mail on the owner's instruction.
  • Storage: OAuth tokens are stored only on the owner's own computer. Email content is processed locally and is not stored on any server operated by this tool.
  • Sharing: no data is sold, shared with, or transferred to third parties.
  • Revocation: access can be revoked at any time at myaccount.google.com/permissions.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
