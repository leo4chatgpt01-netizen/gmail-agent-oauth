# gmail-agent-oauth

gmail-agent（私有仓库）在 Google OAuth「正式版」发布时必须提供的公开首页与隐私政策页，通过 GitHub Pages 托管。只有静态说明文字，不含代码、邮箱或凭据。

## 安装

无需安装。推送到 `main` 后 GitHub Pages 自动发布：

```bash
git push origin main
```

## 使用方法

在 Google Cloud →「Google Auth Platform」→「品牌」中填写：

| 字段 | 值 |
|---|---|
| 应用首页 | `https://leo4chatgpt01-netizen.github.io/gmail-agent-oauth/` |
| 应用隐私权政策链接 | `https://leo4chatgpt01-netizen.github.io/gmail-agent-oauth/privacy.html` |
| 已获授权的网域 | `leo4chatgpt01-netizen.github.io` |
